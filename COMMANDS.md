# 🧠 NEXUS Commands - Quick Reference

## 🚀 **Server Control**
```bash
npm run up        # Start development server
npm run dev       # Start development server (alias)
npm start         # Start production server
npm run down      # Stop NEXUS server
npm run restart   # Restart server
npm run status    # Check if server is running
```

## 🔧 **Port Management**
```bash
npm run kill      # Kill process on port 3000
npm run killall   # Kill all node processes
npm run port      # Check if port 3000 is available
npm run ports     # List all node processes listening
```

## 🧹 **Cleanup & Maintenance**
```bash
npm run clean     # Clear npm cache
npm run verify    # Verify npm cache
npm run fresh     # Delete node_modules & reinstall
npm run logs      # Clear log files
npm run clear     # Clear ports + cache + logs
npm run reset     # Full reset (stop, clear, fresh install, start)
```

## 📦 **Dependencies**
```bash
npm run update    # Update all dependencies
npm run outdated  # Check for outdated packages
npm run audit     # Security audit
npm run fix       # Fix security vulnerabilities
npm run scan      # Run security scan
```

## 🔴 **Redis Operations**
```bash
npm run redis     # Check Redis status
npm run flush     # Flush all Redis data
npm run monitor   # Monitor Redis commands
npm run rinfo     # Redis server info
```

## 📋 **Logs & Debugging**
```bash
npm run tail      # Watch log files in real-time
npm run errors    # Search for errors in logs
npm run info      # Show system information
npm run health    # Check system health
npm run check     # Full system diagnostics
```

## 🆘 **Emergency Commands**
